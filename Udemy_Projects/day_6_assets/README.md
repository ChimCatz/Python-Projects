# Day 6 Assets

These JSON files are world files for the Day 6
`Escaping the Maze` challenge in Reeborg's World.

Files:

- `problem_world.json`
- `problem_world2.json`
- `problem_world3.json`

How to use them:

1. Open Reeborg's World in your browser.
2. Load one of the JSON world files into the site.
3. Write or paste your solution code into the Reeborg editor.
4. Test your code against the different world files.

Important:

- These JSON files are not normal Python imports.
- Your local `day_6_escapingthemaze.py` file is best used as a notes or
  draft file unless you build your own local simulator later.
