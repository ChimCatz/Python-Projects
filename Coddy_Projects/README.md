# Coddy Projects

This folder contains Python practice projects and small exercises outside
the Udemy day-by-day course track.

The main goal here is still learning by doing:

- write the solution first when possible
- use AI/Codex for cleanup, debugging, and structure help
- keep projects understandable instead of over-engineered

## Folder Intent

Use `Coddy_Projects/` for:

- standalone Python exercises
- small tools and practice apps
- experiments that do not belong to the Udemy Day 1 to Day 100 sequence

## Workflow

When updating files here:

- prefer clear names
- keep scripts easy to run directly
- refactor only when it improves readability or learning value
